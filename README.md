## 💻 Local Development & Showcase App

Run the interactive web showcase application locally using **Bun**:

```bash
# Start local development server with Bun
bun x serve .
```

Open `http://localhost:3000` in your browser to explore the live gallery, filter by platform, copy markdown snippets, and use the **Interactive Custom Badge Generator**!
